Vos trades sont chiffrés sur cet appareil et dans votre dépôt. Saisissez votre code pour ouvrir le journal.

Code oublié ? Utiliser le code de secours

Le code de secours est celui affiché (et imprimé) à l'activation du verrouillage. Il ouvre le même journal et permet de choisir un nouveau code.

Sans code ni code de secours, les données restent définitivement illisibles — c'est le prix du chiffrement. Elles ne sont pas perdues pour autant : rien n'est effacé tant que vous ne le demandez pas.

Chiffrement AES-GCM 256 · clé dérivée par PBKDF2 · tout se passe dans le navigateur, aucun compte, aucun serveur.
